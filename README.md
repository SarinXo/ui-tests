# Тестовое задание


## Тест-кейс из 1-й части задания
**Название:** Часть 1. Автоматизация. Работа с полями и формами
1. Открыт браузер
2. Выполнен переход на https://practice-automation.com/form-fields/

**Шаги:**
1. Ввести "admin" в поле Name
2. Ввести "admin" в поле Password
3. Выбрать чекбоксы:
   - Milk
   - Coffee
4. Выбрать радио-кнопку Yellow
5. В dropdown "Do you like automation?" выбрать любое значение
6. Ввести email: name@example.com
7. В поле Message написать количество инструментов, описанных в пункте Automation tools,
   и написать инструмент из списка Automation tools, содержащий наибольшее количество символов
8. Нажать на кнопку Submit
